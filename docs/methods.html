How to read these results → Four claims these tables support and four they do not, with the file each number came from. Also as a PDF.

Each column's range, what it counts and what it must not be read as are printed under the table it belongs to on the leaderboard — including the near-zero human agreement on Faithfulness (Krippendorff's alpha 0.18) and the fact that TRACE is a re-implementation with no human anchor. A number and its caveat should not be separated by a scroll, which is why they are there and this page is here.

Notes counts the notes a protocol could actually read. A model that writes a good note in the wrong shape loses notes to its format, not to its clinical content — read the count before comparing the score.

The chip after a model name is the provider that served it. The same model id on two providers can be two different builds — a different quantisation, different weights, a different system prompt — so they are two rows there, never one.

Rows are only ever compared when they agree on all six of track, harness version, prompt version, judge model, judge prompt version and the settings the judge ran at. A changed judge — or a judge given a different budget to think with — starts a new table rather than rewriting this one. A group that names a judge and cannot say how it was set is withdrawn: two rows that both record nothing are not thereby the same instrument.
