therapy-note-bench

Psychotherapy session notes written by LLMs, scored on published instruments by two independent LLM judges. Code and every score on GitHub; no corpus is redistributed here.

How to read these results → Four claims these tables support and four they do not, with the file each number came from.

Notes counts the notes a protocol could actually read. A model that writes a good note in the wrong shape loses notes to its format, not to its clinical content — read the count before comparing the score.

The last-but-one column is the provider that served the model. The same model id on two providers can be two different builds — a different quantisation, different weights, a different system prompt — so they are two rows here, never one.

Rows are only ever compared when they agree on all six of track, harness version, prompt version, judge model, judge prompt version and the settings the judge ran at — which is why the judge is a switch above and not a column here. What has been withdrawn from the tables, and why, is on the methods page.

Background. The datasets — where each came from, what licence it publishes (two of the six carry one, three publish none, and the sixth shows only a badge), and the traps in them; the method; what a result cannot claim; what exists in this field and what does not; what the endpoint had deployed when.

The drawn numbers are in leaderboard.json; every run behind them is in results/rows.jsonl in the repository. Runs that are measured and not published go to a file outside it.
